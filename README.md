HOMEBD
HOMEBD is an independent Android application for read-only OBD-II vehicle monitoring and diagnostics, with optional Home Assistant integration.
Version: Beta 1.0.0.0
Developer: lufime
Copyright: © 2026 lufime — HOMEBD
License: MIT
Features
Bluetooth Classic OBD-II adapter support
Standard OBD-II/CAN diagnostic communication
Read-only vehicle data
VIN discovery where supported
Live diagnostic data
Optional Home Assistant integration
Real-time HOMEBD telemetry
HOMEBD entities using the sensor.homebd_* namespace
Home Assistant
Home Assistant integration is optional.
The project includes a dedicated HOMEBD integration. It communicates with the Android application through Home Assistant's supported WebSocket interface.
See HOMEASSISTANT_INTEGRATION.md.
